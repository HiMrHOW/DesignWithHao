# 从选择到行动：两个完整示例

Create with Hao｜与卓浩共创 · Zhuohao Wu｜吴卓浩 · v0.2.0

以下人物、对话、预算和反馈均为**虚构演示**，用于展示怎样使用方法，不是真实用户记录、模型测试结果或成功案例。日期、工时与阈值都是例子，不是通用标准。示例中的“已确认”只指虚构人物在情境中确认。

## 示例一：年轻人的起始规划

### 起点与三个关键问题

小林，22岁，设计专业应届生。虚构基准日2026年11月1日。想在产品设计就业、考研和内容创作之间选择。必要生活费用暂由家庭支持，每周可安排6小时探索，90天现金投入上限600元。

访谈不再重复询问年龄和专业，而是补充：

1. 三个方向里，你实际做过哪些代表性任务？——做过课程中的界面原型，没有访谈真实使用者；没体验过研究工作；拍过两条视频。
2. 一年内最重要的变化是什么？——希望具备独立工作的能力，毕业后有收入；不想只为证明自己而考研。
3. 最不能牺牲什么？——按时毕业和正常睡眠；家庭支持到毕业后的范围尚未谈定。

**阶段重点，人物已确认：**完成学业、获得真实岗位体验。家庭支持边界是待确认信息。两条视频与一个课程作业只能算体验线索，不能证明职业优势。

### 比较与暂定方向

| 路径 | 为什么考虑 | 主要未知与代价 | 验证方式 |
|---|---|---|---|
| 产品设计就业 | 与已学技能相连，可积累真实工作经验 | 实际岗位要求、作品质量未核实 | 访谈从业者；做真实小任务并获得反馈 |
| 考研 | 可能适合深入研究某个问题 | 是否喜欢研究；费用和备考机会成本 | 读一篇相关论文，和在读学生交流研究日常 |
| 内容创作 | 喜欢表达，已有少量体验 | 是否愿意持续制作、能否服务具体受众 | 把作品过程整理为一篇说明，观察是否帮助目标读者 |

**已确认的暂定主路径：**优先验证产品设计就业；考研保留为备选，内容表达作为解释作品的能力练习。不是立即认定一生做产品设计。若真实任务体验持续不适配，或研究体验明显更有投入意愿，再重开比较。

### 三个时间尺度

- **5—10年情景：**能独立解决实际问题、有稳定生活和持续学习空间；可以走专业设计、研究或跨领域产品方向，不预设职位和收入。
- **1年方向：**按时毕业，完成两份经外部反馈迭代的作品，获得一次与候选方向相关的真实协作或工作经历。能否获得岗位依赖市场与能力证据，不作保证。
- **90天：**2026-11-01至2027-01-29，首日计第1天，共90个日历日。这里只验证选择，不要求同时建立自媒体业务。

| 时间 | 动作与责任 | 上限 | 观察与决定 |
|---|---|---|---|
| 11月1—14日 | 本人整理作品；邀请2名从业者和1名在读学生交流，先征得对方同意 | 每周5小时；交通等累计≤150元 | 能否描述实际任务与进入条件；未约到就换公开课程/岗位资料并注明证据较弱 |
| 11月15—30日 | 本人为一个可接触的使用者完成小型原型；做一次研究阅读练习 | 每周5小时；累计新增≤150元 | 比较真实任务中的投入意愿和困难；11月30日复查主路径 |
| 12月1—30日 | 根据反馈修改原型；写一篇作品过程说明；向2位相关从业者征求意见 | 每周5小时；累计新增≤200元 | 12月30日看作品能否清楚证明解决了什么问题；缺反馈则缩小范围，不继续堆作品 |
| 12月31日—1月29日 | 本人完成作品展示并寻找合适的真实协作/实习机会 | 每周5小时；累计新增≤100元 | 1月29日比较证据，决定继续就业路径、补技能或重新比较；不以回复数量单独定义能力 |

每周分配：作品3小时＋了解岗位/研究1小时＋反馈与复盘1小时＝5小时；6小时上限中留1小时缓冲。现金上限150＋150＋200＋100＝600元，非必须全部花完。考试周将探索降到2小时并顺延范围，不压缩睡眠。

本周第一步：选一份已有作业，写清“想解决的问题、做过什么、还不知道什么”，再发出一条有具体问题的交流邀请。暂不购买昂贵课程，不承诺日更。

### 示范复盘与续接

**虚构第30天反馈：**访谈完成2次；原型反馈显示问题定义过宽；研究阅读有兴趣，但还不足以支持考研选择。下一阶段缩成一个核心使用场景，维持主路径，考研继续待验证。

```text
方法：life-path-design v0.2.0
记录日期：2026-11-30；虚构示例
目标：完成学业，验证独立工作的能力；不牺牲睡眠。
已确认：先验证产品设计就业；考研备选，内容仅辅助作品表达。
事实状态：任务和访谈均为人物自述；招聘要求仍需本人核实。
约束：每周6小时，其中行动5小时、缓冲1小时；90天合计≤600元。
新反馈：原型问题过宽，先缩小场景；家庭支持范围仍待沟通。
下一步：12月30日前迭代一个核心场景并取得外部反馈。
分享范围：只分享脱敏作品，不公开访谈者身份或私人对话。
```

## 示例二：中年人的复盘与重新规划

### 起点与三个关键问题

陈宁，44岁，有15年运营经验，现职稳定但职责零散。虚构基准日2026年11月1日。希望找回专业主动性，同时每周保留两个晚上陪伴家人。考虑内部调整、转行、业余顾问，每周最多4小时做探索；本阶段不需要增加家庭财务风险。

1. 最想保留哪类工作，最想退出什么？——喜欢把复杂流程讲清楚，不想继续承担没有明确负责人的临时救火。
2. 两个晚上与现职责任的冲突在哪？——主要来自临时会议，是否能改排还未与主管谈定。
3. 独立顾问已有客户证据吗？——两位熟人表达过兴趣，没有明确需求或付费承诺；公司对兼职的约定需要核实。

**阶段重点，人物已确认：**恢复家庭时间、积累可迁移的流程改进能力。过去组织过内部培训属于能力线索；熟人兴趣不是顾问收入。

### 路径与参与方式

| 路径/事项 | 判断 | 参与方式与前提 |
|---|---|---|
| 内部调整职责 | 暂定主路径，较能保留稳定性并减少无序工作 | 本人向主管提一个边界清晰的流程改进试点；需主管明确范围与会议安排 |
| 跨行业求职 | 保留备选，暂不广泛投递 | 每月了解一个目标岗位，核对可迁移能力和差距 |
| 业余顾问 | 暂缓承诺，只做小规模需求了解 | 先核实雇佣约定；不使用公司保密材料；报酬、责任未定前不接实施任务 |
| 每天发布内容 | 暂停 | 目前没有传播需要和时间；先形成可展示且获准公开的成果 |
| 临时救火工作 | 重谈，不假定已委托 | 列出接手人、工作说明与移交时间；没有主管和接手人确认就仍计入本人工时 |

如果主管拒绝任何职责调整且连续影响家庭安排，内部路径的关键假设失效，提前启动外部岗位比较。不能用“交给团队”假装腾出了时间。

### 三个时间尺度与90天投入

- **5—10年情景：**稳定发挥专业能力，工作可预期，与家人有固定相处时间；可做组织内专家，也可在客户证据充分后探索有限独立服务。
- **1年方向：**形成一项可验证的流程改进成果，建立更清晰的职责边界；争取多数周落实两个家庭晚上。若组织条件不支持，转入外部岗位比较。
- **90天：**2026-11-01至2027-01-29，首日计第1天。探索现金上限300元，不影响必要家庭支出。职业与家庭安排均需相关人协商，不能由计划单方面宣布生效。

| 时间 | 动作与负责人 | 证据和复查条件 |
|---|---|---|
| 至11月14日 | 本人记录一周任务；与家人确认晚间安排；向主管提出试点与会议调整 | 是否明确试点范围、时间和负责人；未获同意则不计为已减少工作 |
| 至11月30日 | 获准后在现职工时内完成一个小试点；本人在探索时间整理一份脱敏能力说明 | 观察返工、交接清晰度等可取得的数据；11月30日核查是否真有改善 |
| 至12月30日 | 本人在4小时探索额度内完成2次行业交流；若可行再了解1个顾问需求 | 问题、服务范围、进入条件是否具体；兴趣表达不记为订单 |
| 至1月29日 | 本人比较家庭晚间落实情况、试点反馈与外部机会证据 | 1月29日决定继续内部路径、转外部求职验证或停止顾问探索；现金和时间超限即缩减 |

每周探索：整理成果1.5小时＋交流/岗位核实1小时＋家庭协商与复盘0.5小时＝3小时，另留1小时缓冲，总计4小时。现职试点必须替换原有任务、放在原工作时段，不算免费新增劳动；如不能替换，缩小或暂停。陪伴家人的两个晚上独立保护，不算“剩余可用工时”。300元仅作必要交通等上限，不安排付费课程。

本周第一步：记录导致晚间工作的一类重复问题，准备一页调整建议。尚未明确的顾问权益、接手人和主管承诺不计为已有资源。

### 示范复盘与续接

**虚构第60天反馈：**主管同意了范围较小的试点，但部分会议仍占晚间；熟人需求很模糊，顾问暂不推进。决定继续试点、重谈一项会议安排，同时用原有交流时段了解外部岗位，不增加总工时。

```text
方法：life-path-design v0.2.0
记录日期：2026-12-30；虚构示例
目标：专业主动性与两个家庭晚上；稳定性仍优先。
已确认：内部试点继续；顾问暂缓；外部岗位保留备选。
事实状态：试点与会议反馈为人物自述，没有付费客户承诺。
约束：每周探索4小时，含1小时缓冲；90天现金≤300元。
关键假设：组织能容纳职责与会议调整，仍未充分验证。
下一步：1月29日复查家庭时间和试点结果；若约束持续冲突则重选路径。
分享范围：只分享脱敏经验，不分享公司的流程细节和联系人身份。
```

两个例子都以取得新证据为目标。选择没有“正确人设”的标准答案；可用的方法应允许发现原计划不合适，然后有依据地改变它。
