> 把想要的生活，变成可以验证的下一步。

吴卓浩（Zhuohao Wu），产品设计与AI创造力研究者、创业者，中国传媒大学副教授，曾任创新工场人工智能工程院副总裁及Google、Airbnb中国产品设计负责人，著有《AI创造力：智能产品设计与研究》。这套方法把产品创新、创业辅导与教学中的问题界定、方案比较、实践验证和反馈迭代，用于年轻人的起始规划与中年人的复盘。职业经历可参见[清华大学出版社作者介绍](https://www.tup.com.cn/booksCenter/book_09549101.html)，人机共创研究参见[Springer论文](https://link.springer.com/chapter/10.1007/978-3-030-78462-1_13)。这些经历说明方法的实践背景，不代表人生规划效果已获验证。

## 这套方法帮助谁

主要覆盖**年轻人的起始规划**与**中年人的复盘与重新规划**。帮助你把生活目标、现实约束、已有积累与外部机会放在一起，决定投入什么、暂停什么，以及下一步怎样验证。发展事业、积累财富与建立个人IP可以成为目标，也可以选择稳定工作、家庭、健康、学习或创造；优先级由使用者确认。

它是一套开放的方法与工作表，同时提供跨模型使用的skill。**AI不是必需条件**：你可以自己填写、和同伴讨论，也可以让AI帮助访谈、整理证据和比较路径。

## 从这里开始

| 使用方式 | 操作 |
|---|---|
| 普通AI聊天，最容易开始 | 打开[单文件对话版 PORTABLE.md](PORTABLE.md)，上传或复制全文，再发送下面的启动语 |
| 支持 Agent Skills 的客户端 | 下载本仓库，将其保存为 `life-path-design` 文件夹，按客户端官方方式添加，保留 `SKILL.md` 与 `references/` 的相对位置 |
| 不使用AI | 阅读[核心流程](SKILL.md)，选择[青年起步](references/early-life.md)或[中年复盘](references/midlife.md)，填写[工作表](references/workbook.md) |

**起始规划启动语：**

> 请使用这套人生与事业设计方法，帮助我做起始规划。我目前处于____阶段，在____之间犹豫。请先了解我想要的生活、现实约束和已有体验，每轮问1—3个关键问题，逐步给出路径比较与90天试验。

**中年复盘启动语：**

> 请使用这套人生与事业设计方法，帮助我复盘与重新规划。我目前最想改变的是____，希望保留的是____。先利用我已提供的信息，与我确认优先级，再比较未来路径、决定投入和停止的事项，形成1年方向、5—10年情景与90天行动。

无需先整理完整人生档案。先说当前选择、希望的改变和最重要的约束；信息不足时先得到条件化方案，再补证据。

## 方法怎样运转

| 步骤 | 核心问题 | 留下的结果 |
|---|---|---|
| 1. 确认重点 | 我想过怎样的生活？什么不能牺牲？ | 本阶段2—3项重点与约束 |
| 2. 回看积累 | 什么做过、有效、愿意继续？ | 有证据的能力与资源清单 |
| 3. 比较路径 | 除了当前倾向，还有什么可选？ | 2—3条路径、代价和关键未知 |
| 4. 选择方向 | 哪条路径更适合此阶段？ | 暂定主路径、备选与必要的定位 |
| 5. 配置投入 | 保留、试验、委托、暂停什么？ | 角色、时间、资金与退出条件 |
| 6. 设计试验 | 90天内如何获得有用反馈？ | 与1年方向、5—10年情景相连的行动 |
| 7. 复盘调整 | 实际发生了什么？要改变什么？ | 更新后的计划与可携带记录 |

一次初步规划结束，应至少得到：**阶段重点、路径选择依据、关键假设、近期动作、时间与资金上限、下一次复查条件**。完整规划再补齐三个时间尺度。局部问题可以只做有关步骤，不必每次填全套表。

每周简短回顾行动，第30/60天检查假设，第90天决定继续、调整或停止；可按生活节奏调整。规划不是一次生成的终身答案。

## AI兼容范围

本方法不依赖厂商API、联网、代码执行、付费账户或平台记忆。原生skill能否安装取决于客户端；上传文档不等于安装skill。普通对话模式取决于模型的中文理解、上下文容量和指令遵循能力。

有联网能力时核实当前岗位、市场、政策和费用；没有时列出待核实项。没有文件能力时在对话中输出可复制文本。换模型时携带工作表中的“规划续接记录”，无需交出全部聊天或私人档案。上下文较小时，分段提供核心流程、适用路径与工作表。

**目前完成的是文件结构和内容一致性检查，尚未完成独立的跨模型行为实测，也不宣称已验证人生改善效果。**模型可能遗漏约束，重要决定须结合现实反馈，由使用者确认。

## English overview

**Create with Hao — Life Path Design, by Zhuohao Wu (吴卓浩).** An open, Chinese-language method for early-life planning and midlife review. Clarify life priorities, review experience and resources, compare possible paths, and turn a one-year direction and 5–10-year scenarios into bounded 90-day experiments.

Use it on your own, with a peer, or with an AI assistant. `SKILL.md` is the entry point for compatible Agent Skills clients; `PORTABLE.md` is a self-contained conversation version. No vendor API or online tool is required. Cross-model behavioral testing and real-world outcome validation have not yet been completed. Original materials are licensed under CC BY-SA 4.0. This release is primarily in Chinese; it is not a complete English edition.
